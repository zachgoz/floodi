# Antigravity Agent Orchestration

Welcome to the Floodi Agent Team. This directory contains the configuration and logic for our specialized AI agents. By using this multi-agent system, we move away from generic assistance to a high-performance, specialized development workflow.

## The Team

| Agent | Persona | Role | Focus Area |
| :--- | :--- | :--- | :--- |
| **Mike** | Lead Engineer | Orchestrator | Architecture, Planning, Delegation |
| **Alex** | UI/UX Designer | Specialist | Premium Aesthetics, CSS, Layout |
| **Sam** | Full Stack Dev | Specialist | Feature Logic, API, Firebase |
| **River** | Researcher | Specialist | Tide Science, Hydrography, Data Integrity |

## How to Use

### 1. The Orchestration Flow
Always start a new feature or complex bug fix with **Mike (Lead Engineer)**. 
- **Prompt Example**: *"Mike, we need to implement a new dashboard for surge predictions. Please break this down."*
- **What happens**: Mike will analyze the request and create "missions" for Alex, Sam, or River.

### 2. Switching Personas
Once Mike has delegated a task, you can interact directly with the specialist or let the **Antigravity Agent Manager** handle the transition.
- **Tip**: Mentioning the agent's name (e.g., *"Alex, take the mission from Mike and design the UI"*) helps the system maintain context.

## Best Practices

### 🚀 Delegation First
Don't ask the Lead Engineer to write CSS or specific API logic. His mandate is to **delegate**. If you find Mike doing too much manual work, remind him to delegate to Alex or Sam.

### 📋 Mission-Based Tasks
When delegating, ensure the agent produces a `task.md` or `implementation_plan.md`. This allows you to review their logic before they start making changes to the codebase.

### 🔬 Scientific Source of Truth
For anything involving tide data, NOAA APIs, or datum conversions, consult **River** first. Use her research artifacts as the technical specification for Sam's implementation.

### 🎨 Premium UI Baseline
**Alex** is programmed to avoid browser defaults. If a UI component looks too "basic," a single prompt to Alex (*"Alex, make this look more premium"*) will trigger his glassmorphism and modern design rules.
