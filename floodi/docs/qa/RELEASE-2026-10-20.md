## Limits and follow-up

The pilot is unpaid, uses the shared gauge advisory, and makes no validated street-depth, road-safety or guaranteed forecast-accuracy claim. Owner receipt establishes the direct provider connection. Production enrollment-to-worker-to-opt-out delivery has not been exercised with a consenting real subscriber in this release verification; it remains covered by emulator/HTTP tests and is the next pilot acceptance check.

Dependency cleanup remains open: npm audit --omit=dev reports 25 app dependency advisories (3 critical, 14 high, 8 moderate). The audit package modules were absent from all 19 matching browser source maps; no concrete browser exploit path was identified for the static Hosting build. These largely concern Node transports and build/server tooling; this is not a clean dependency audit or a separate Functions runtime audit. Avoid blind audit fix --force and address updates in a reviewed maintenance pass. Automated bounce/complaint handling, retention cleanup, paid billing/entitlement and street calibration remain commercialization work.
